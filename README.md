# Desculpas Express

O 'Desculpas Express' é um projeto que apresenta uma plataforma criada para oferecer sugestões de mensagens para diferentes situações do cotidiano, como atrasos, esquecimentos, compromissos perdidos e respostas demoradas.

O site foi desenvolvido utilizando HTML, CSS e Bootstrap, contando com quatro páginas principais: Início, Serviços, Sobre Nós e Contato. Entre os elementos utilizados estão uma navbar responsiva, cards, botões, formulário, sistema de grid e modais com informações adicionais sobre os serviços. Também foi criada uma seção especial de promoção para apresentar uma oferta.

O projeto tem como objetivo colocar em prática os conhecimentos de desenvolvimento web, explorando a estruturação de páginas, a estilização com CSS e a utilização dos componentes do Bootstrap para criar um site organizado, atrativo e adaptável a diferentes tamanhos de tela.
